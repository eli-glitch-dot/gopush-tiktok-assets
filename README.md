# GOPUSH TikTok assets

Public image hosting for GOPUSH's scheduled TikTok photo posts (@gopush.app). Contains only finished 1080x1920 JPEG slides and `manifest.json`.

- `posts/post-XXX/slide-NN.jpg`: slides in posting order (`slide-01` is the cover)
- `manifest.json`: caption, publish time (America/New_York) and ordered image URLs per post

No code, credentials or private data live here.
